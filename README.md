# Todo Scheduler

## Описание проекта
**Todo Scheduler** — это простой планировщик задач с веб-интерфейсом.  
Проект позволяет создавать, редактировать и отслеживать задачи с возможностью установки повторяющихся напоминаний.  
Цель проекта — автоматизация управления задачами и обучение работе с Go, HTTP-серверами и SQLite.

## Выполненные задания
- Создание структуры проекта с разделением на пакеты (`pkg/db`, `pkg/api`)  
- Реализация базы данных на SQLite и функций работы с задачами  
- Настройка веб-сервера для фронтенда и API  
- Обработка повторяющихся задач (ежедневно, еженедельно, ежемесячно, ежегодно)  
- Интеграция с HTML/CSS фронтендом
